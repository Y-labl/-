# 小霸王 - 梦幻西游手游自动化脚本 逆向分析报告

## 1. 项目概览

**项目名称**: 小霸王  
**目标游戏**: 梦幻西游手游 (Fantasy Westward Journey Mobile)  
**项目类型**: 游戏自动化脚本 (Game Bot)  
**打包方式**: PyInstaller (Python 3.8/3.9) + Java JAR  
**支持平台**: Windows (通过 ADB 控制 Android 设备/模拟器)  
**支持服务器**: 点卡服、畅玩服

### 2.1 Python 层 (GUI + 胶水代码)

| 组件 | 作用 |
|------|------|
| PyQt5 | 桌面 GUI 框架 (窗口、按钮、设置面板) |
| pyqt_toast | 浮动 Toast 通知组件 |
| pyqt_resource_helper | 资源加载辅助 (CSS等) |
| Python-Java 桥接 | 通过 JNI/进程调用与 subor.jar 通信 |

### 2.2 Java 层 (subor.jar - 核心引擎)

| 推测模块 | 功能 |
|----------|------|
| 任务调度引擎 | 管理自动化任务的执行顺序和条件 |
| ADB 通信层 | 封装 adb 命令，实现点击/滑动/截图 |
| 图像识别引擎 | OpenCV 模板匹配 + OCR 文字识别 |
| 游戏状态机 | 管理游戏当前状态 (登录/战斗/摆摊/跑图等) |
| 脚本执行器 | 执行预定义的自动化流程 |

### 2.3 关键依赖

| 库 | 用途 |
|----|------|
| **OpenCV (cv2.pyd)** | 图像识别：截图模板匹配、UI元素定位 |
| **NumPy** | 图像数组处理 |
| **Pillow (PIL)** | 图像格式转换、截图预处理 |
| **adbutils** | Android ADB 协议封装，设备通信 |
| **PyWin32** | Windows API (窗口管理、进程操作) |
| **psutil** | 进程监控 |
| **av (PyAV)** | 视频录制/回放 (可能用于录屏功能) |
| **PyQt5** | GUI 界面 |

### 3.3 图像识别机制

脚本使用 **模板匹配 (Template Matching)** 作为核心识别技术:

```
工作流程:
1. ADB 截取设备当前画面 (screencap)
2. 将截图传输到 PC
3. 使用 OpenCV cv2.matchTemplate() 与预存模板匹配
4. 获取匹配位置 (x, y) 坐标
5. 通过 ADB 执行点击/滑动操作
```

**为什么有两套模板?**
- 点卡服和畅玩服的 UI 风格/配色不同
- 需要分别准备匹配模板以确保识别准确率

## 4. 通信架构

```
┌──────────┐     ADB/USB/WiFi     ┌──────────────┐
│  小霸王    │ ◄──────────────────► │ Android 设备  │
│  (PC)     │                     │ (手机/模拟器) │
│           │  1. adb shell       │              │
│  Python   │     input tap x y   │  梦幻西游手游 │
│  + Java   │  2. adb shell       │              │
│           │     screencap -p    │              │
│           │  3. adb pull        │              │
│           │     screenshot.png  │              │
└──────────┘                     └──────────────┘
```

### ADB 命令封装

脚本通过 adbutils 库封装了以下 ADB 操作:
- `adb shell input tap X Y` - 模拟点击
- `adb shell input swipe X1 Y1 X2 Y2` - 模拟滑动
- `adb shell screencap -p` - 截图
- `adb shell input keyevent KEYCODE` - 按键事件
- `adb devices` - 设备检测

## 5. 安全与反检测

根据模板截图推测的反检测手段:

1. **随机延迟**: 操作间添加随机时间间隔
2. **仿人类操作**: 点击位置添加随机偏移
3. **验证码处理**: "坚持摆摊" 等游戏内验证机制自动响应
4. **异常恢复**: 网络断开、弹窗等自动处理
5. **多服务器适配**: 针对不同服务器 UI 差异使用不同模板

## 7. 反编译建议

### 7.1 Java 反编译 (subor.jar)

```bash
# 方法1: jadx (推荐)
# 下载 jadx-gui: https://github.com/skylot/jadx/releases
jadx-gui subor.jar

# 方法2: CFR
java -jar cfr.jar subor.jar --outputdir decompiled/

# 方法3: IntelliJ IDEA
# 直接将 subor.jar 拖入 IDEA 即可查看反编译源码
```

### 7.2 Python 反编译

```bash
# 1. 提取 PyInstaller
pip install pyinstxtractor
python -m pyinstxtractor 小霸王.exe

# 2. 反编译 .pyc
pip install uncompyle6
uncompyle6 -o ./python_source/ extracted/*.pyc

# 3. 或使用 pycdc
pycdc extracted/main.pyc > main.py
```

### 7.3 建议顺序

1. **先反编译 subor.jar** - 这是核心业务逻辑所在
2. 再提取并反编译 Python 主脚本 - 了解 GUI 和配置逻辑
3. 结合 逻辑素材/ 目录理解完整业务流程

## 8. 总结

小霸王是一个**技术完整度很高的梦幻西游手游自动化脚本**，其核心特点:

- **双层架构**: Python(PyQt5 GUI) + Java(核心引擎)
- **基于图像识别**: 使用 OpenCV 模板匹配而非内存修改，检测风险较低
- **功能全面**: 覆盖摆摊、跑图、NPC交互、跑玉等主流自动化需求
- **双服适配**: 同时支持点卡服和畅玩服
- **异常处理完善**: 自动应对网络异常、弹窗、安全验证等

核心技术栈: Python 3.8+ / Java / PyQt5 / OpenCV / ADB / NumPy
