### 3.2 任务调度层 (ThreadManager)

单例模式管理所有任务线程:

```
ThreadManager
+-- baoTuThreads: []        # 宝图线程
+-- paoYuThreads: []        # 跑玉线程
+-- cwChangJingThreads: []  # 畅玩场景线程
+-- dkChangJingThreads: []  # 点卡场景线程
+-- genDuiThreads: []       # 跟队线程
```

每个线程继承 QThread，核心方法: setDealOrder(), run(), stop()

### 3.3 识别引擎层

#### 3.3.1 场景定位 (detect_position_util.py - 117KB)

**原理**: 通过预定义每个地图的像素点阵指纹来识别当前所在位置。

- 畅玩服: 8个地图指纹 (长安城/傲来国/建邺城/长寿村/朱紫国/西梁女国/宝象国/江南野外)
- 点卡服: 50+个地图指纹 (长安城/傲来国/建邺城/九黎城/长寿村/朱紫国/西梁女国/宝象国/江南野外/伊阙龙门/女娲神迹/丝绸之路/长安酒店/大唐国境/东海渊/东海湾/花果山/女魃墓/墨家村/女儿村/长寿郊外/大唐境外/大唐官府/北俱芦洲/万界通廊/魔王寨/战神山/神木林/芙蓉国/化生寺/地府/普陀山/解阳山/幻境花果山/碗子山/无底洞/龙宫/龙窟五层/龙窟六层/凤巢四层/凤巢三层/小西天/子母河底/天宫/麒麟山/方寸山/五庄观/盘丝岭/青丘/凌波城/狮驼岭/天机城/五行山/鬼市)

**坐标解析**: 从画面顶部 (62-128)x51y 范围检测白色括号，提取X/Y坐标数字。

#### 3.3.2 颜色状态检测 (color_util.py - 22KB)

检测各种游戏内界面状态:
- 弹窗检测: 成就弹窗、网络错误弹窗
- 隐藏界面: 检测界面边缘特定像素颜色判断隐藏菜单/任务栏/摊位状态
- 物品栏: 判断背包格子是否为空/被锁定
- 血蓝检测: 通过特定区域颜色计算百分比
- 战斗检测: 通过好友入口按钮位置判断是否在战斗中
- 四小人检测: 通过第三方API识别重叠NPC点击位置

#### 3.3.3 OpenCV模板匹配 (img_util.py)

- 主要函数: findPic(), findPics(), findOneFromPics(), waitAssertImgOk()
- 匹配 逻辑素材/ 目录下的278张PNG截图模板
- 支持随机偏移点击、多图搜索、循环等待

### 3.4 控制层

#### 3.4.1 scrcpy_util (单例)

- 封装pyscrcpy客户端，每设备一个连接
- 配置: 800x448分辨率, 8Mbps码率, 10fps
- 提供: getFrame(), getSize(), isLandscape(), getPointColor()

#### 3.4.2 click_util

- click(deviceId, point, offset=QPoint(5,5)): 带随机偏移点击
- drag(deviceId, touchPoints): 平滑拖动
- 通过scrcpy发送触摸事件 (ACTION_DOWN/MOVE/UP)
- 支持双击、带随机偏移

#### 3.4.3 adb_util

- 设备发现: 通过adbutils列出所有ADB设备
- 分辨率管理: wm size获取/修改设备分辨率
- 游戏信息获取

## 四、业务功能详解

### 4.1 点卡场景自动 (DKChangJingThread)

这是最复杂、最核心的自动化模块，实现游戏内全自动挂机。

```
run() 主循环:
  1. checkXueLan()
     - 检测当前血蓝百分比
     - 低于阈值时自动使用: 秘制/红碗/蓝碗/酒肆
     - 支持烹饪/酒肆技能恢复

  2. checkWuYi()
     - 检测装备耐久度/武器消耗
     - 必要时自动补充

  3. detectPosition()
     - 获取当前所在地图名称
     - 获取当前X,Y坐标
     - 确认是否在目标地图

  4. [抓宠模式] findSideTargetPoints()
     - 遍历可捕捉的召唤兽列表
     - 通过模板匹配找到野怪
     - 自动点击进入战斗
     - 使用捕捉技能

  5. [偷窃模式] toutouDoOverCheck()
     - 寻找可偷窃的目标
     - 执行偷窃操作
     - 处理偷窃后的战斗

  6. [自动寻路] startDuiZhang()
     - findNpcAndClickLogic(): 找NPC对话/交互
     - goToMapAction(): 使用飞行符/传送阵跨地图传送
     - randomClickMap(): 当前地图随机巡逻点击

  7. isInPk() -> [战斗中处理]
     - 技能攻击 / 普通攻击 / 防御 / 自动 / 逃跑 (五选一)
     - 自动选择召唤兽参战
     - 处理战斗结束后的弹窗

  8. 异常处理
     - 关闭各类弹窗 (成就/升级/网络重连)
     - 物品栏已满 -> 自动清理/出售
     - 坚持摆摊按钮处理
     - 掉落物品自动拾取

  9. 循环控制
     - 按配置间隔执行
     - 支持暂停/停止
     - 日志记录所有操作
```

**战斗策略 (五选一互斥)**:
| 模式 | 说明 |
|------|------|
| 点选技能后自动战斗 | 先使用技能，然后开自动 |
| 普通攻击后自动战斗 | 普攻一次后开自动 |
| 防御后自动战斗 | 防御一回合后开自动 |
| 直接自动战斗 | 直接挂自动 |
| 逃跑 | 遇敌直接逃跑 |

### 4.2 畅玩场景自动 (CWChangJingThread)

简化版挂机模块:
- 自动寻路到目标地图和位置
- 随机点击地图进行巡逻
- 遇敌自动战斗(简化版)
- 血蓝自动恢复

### 4.3 其他功能

| 功能 | 消耗 | 说明 |
|------|------|------|
| 宝图 | 2币/天 | 自动完成挖宝图任务全流程 |

| 跟队 | 1币/天 | 跟随队伍自动战斗、自动寻路 |

### 4.4 通用操作模块 (game_action/)
