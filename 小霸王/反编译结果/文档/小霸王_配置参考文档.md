## 1. 点卡场景配置 (DKChangJingConfig)

### 配置文件结构

配置以 JSON 格式存储在订单的 dkchangjingconfig 字段中。

```json
{
  "roleAddXueMode": "秘制",
  "roleAddLanMode": "秘制",
  "roleXuePercent": 30,
  "roleLanPercent": 30,
  "isZhua": false,
  "isTou": false,
  "isPkJiNeng": false,
  "isPkPuGong": false,
  "isPkFangYu": false,
  "isPkAuto": false,
  "isPkTaoPao": false,
  "isDuiZhang": true
}
```

### 字段说明

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| roleAddXueMode | string | "秘制" | 人物加血方式: 秘制/红碗/酒肆 |
| roleAddLanMode | string | "秘制" | 人物加蓝方式: 秘制/蓝碗/酒肆 |
| roleXuePercent | int | 30 | 血量低于此百分比时自动补充 |
| roleLanPercent | int | 30 | 蓝量低于此百分比时自动补充 |
| isZhua | bool | false | 抓宠模式开关 |
| isTou | bool | false | 偷窃模式开关 |
| isPkJiNeng | bool | false | 战斗策略: 使用技能(五选一) |
| isPkPuGong | bool | false | 战斗策略: 普通攻击(五选一) |
| isPkFangYu | bool | false | 战斗策略: 防御(五选一) |
| isPkAuto | bool | false | 战斗策略: 自动(五选一) |
| isPkTaoPao | bool | false | 战斗策略: 逃跑(五选一) |
| isDuiZhang | bool | true | 队长模式: 自动寻路/带队 |

> **注意**: 战斗策略五项 (isPkJiNeng / isPkPuGong / isPkFangYu / isPkAuto / isPkTaoPao) 互斥，同一时间只能启用一个。

### 配置界面

由 `dk_changjing_config_win.py` 提供可视化配置:
- 加血/蓝方式: 下拉选择框
- 血蓝阈值: 滑块 (0-100%)
- 抓宠/偷窃: 开关按钮
- 战斗策略: 开关按钮 (互斥)
- 自动寻路: 开关按钮

## 6. 全局配置 (const.py)

### API 地址

```python
API_HOST = "http://111.229.123.236:3000"
```

### 应用版本

```python
AppVersion = 30   # 当前版本号
OpenId = 1        # 开放ID
```

### 时间配置

```python
PingTime = "00:00:00.000Z"  # 抢平转基准时间
waitServerT = 6              # 等待服务器时间
```

### 游戏服务器 (运行时切换)

```python
gameType = "点卡服"  # 或 "畅玩服"
```

通过主窗口右上角 `切换点卡服 / 切换畅玩服` 按钮动态切换。

## 8. 日志配置

日志文件存放: **./有效日志/**

```python
logger.add("有效日志/runtime_{date}.log",
    encoding="utf-8",
    rotation="1 day",
    retention="15 days",
    compression="zip")
```

每个订单独立日志目录: `有效日志/{orderId}/{date}/{hour}.txt`

## 10. 快捷键/按钮配置

| 按钮 | 功能 |
|------|------|
| 开始 (PLAY图标) | 启动任务线程 |
| 刷新 (SYNC图标) | 刷新订单详情 |
| 删除 (DELETE图标) | 删除当前订单 |
| 备注 | 设置订单备注 |
| 绑定设备 | 选择并绑定ADB设备 |
| 截图 | 截取当前游戏画面 |
| 预览 | 打开实时画面预览窗口 |
| 深色/浅色主题 | 切换界面主题 |
| 置顶 (PIN图标) | 窗口置顶/取消置顶 |
